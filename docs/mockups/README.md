# 配車計画表「情報量削減」提案モックアップ

`index.html` の配車計画表（D&D配車ビュー）の情報量をできる限り減らす、という観点での
デザイン提案モックアップです。実アプリの `:root` デザイントークン（`--accent:#3BB888` /
ブロック色 `#1a7a5e` / 行高 52px など）をそのまま流用して、見た目の連続性を保っています。

| ファイル | 内容 | 削減の軸 |
| --- | --- | --- |
| `00-current.*` | 現状（参考） | — |
| `A-minimal-gantt.*` | 案A：色バーだけミニマル・ガント | 視覚的減量（装飾と文字を限界まで削り、詳細はホバー） |
| `B-driver-summary.*` | 案B：ドライバー別 1行サマリ | 構造的減量（時間軸の2次元グリッドを1次元リストへ） |
| `C-exception-focus.*` | 案C：要対応だけの例外フォーカス | 内容的減量（正常な配車は畳み、対応が必要な案件のみ） |

各案は `*.html`（単体で閲覧可）と `*.png`（スクリーンショット）で出力しています。

## 再生成

```bash
cd docs/mockups
ln -sfn "$(npm root -g)" node_modules           # グローバルの playwright を解決
PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers node build.mjs
```

`build.mjs` 内のサンプルデータ・トークンを編集すると、4画面が一括で再生成されます。
